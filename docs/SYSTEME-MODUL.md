# Codex zu deinem Agentic OS hinzufügen

Der Lektionstext für das Setup-Modul liegt im Vault-Planning als Resource Pack (`14-codex-addon.md`) und wird direkt in die Skool-Lektion übernommen: Titelbild, ein Satz, vier Punkte, Ablauf, Einrichtung, Setup-Prompt.

Der Setup-Prompt selbst ist `SETUP-PROMPT.md` in diesem Repo. Er ist die einzige Quelle für den Prompt; der Lektionstext zitiert ihn unverändert.

Download für Mitglieder: https://github.com/sebaskauf/agentic-os-codex-addon/releases/latest/download/agentic-os-codex-addon.zip
